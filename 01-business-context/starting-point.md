# Starting Point

## The situation

At the start of the project, the website was not built around organic growth. It functioned mainly as an online company flyer. It explained who the company was and what it did, but it was not structured around the problems potential customers and candidates were actually trying to solve.

Organic traffic was approximately:

**~2,000 monthly visitors**

But the bigger issue was underneath the traffic number. Several basic SEO and measurement foundations were missing.

---

## 1. Measurement was incomplete

Google Search Console was not properly set up. GA4 and Google Tag Manager were also not properly implemented. This meant we had limited visibility into:

- Organic search performance
- Search queries
- Landing-page performance
- User behaviour
- Conversion paths
- Technical search issues

Before making larger SEO decisions, we first needed reliable measurement.

---

## 2. Around 70% of the website was not indexed

One of the clearest technical issues was indexation. Approximately **70% of the website was not indexed by Google**. This meant a large part of the website had little or no opportunity to generate organic visibility. Before focusing heavily on rankings or content growth, we first needed to understand why important pages were not being indexed and improve the technical foundation. The first principle was simple:

A page cannot generate organic traffic if search engines cannot properly discover and index it.

---

## 3. The website had no clear search focus

The website was primarily structured around explaining the company. It was not designed around how people actually searched. There was no strong focus on important search opportunities such as vacancies and other high-intent landing pages. Instead of supporting a clear search journey, the website largely operated as an online flyer. This limited both organic discoverability and the commercial value of the traffic that did arrive.

---

## 4. Content described the company instead of solving the searcher's problem

A large part of the existing content focused on: **What we do** rather than: **What problem are you trying to solve?**

That difference became an important part of the SEO strategy. Search behaviour usually starts with a need, question or problem. The content therefore needed to move from company-focused communication toward search-intent-driven content. The shift was:

**Company → Service → Search intent → Problem → Solution**

Instead of only describing services, pages needed to answer why someone was searching in the first place.

---

## 5. Technical performance needed improvement

Website performance also created an opportunity. The initial performance score was approximately: **40** Through technical and website improvements, this increased to approximately: **88** The objective was not to optimise a score for its own sake. Better technical performance supported:

- Faster page experiences
- Stronger technical SEO foundations
- Better usability
- More reliable crawling
- A stronger conversion experience

Performance was therefore treated as part of the wider growth system rather than as an isolated development metric.

---

## Starting-point summary

The initial situation looked roughly like this:

| Area | Starting point |
|---|---|
| Organic traffic | ~2,000 monthly visitors |
| Google Search Console | Not properly implemented |
| GA4 / GTM | Not properly implemented |
| Indexation | ~70% of website not indexed |
| Website purpose | Primarily an online company flyer |
| Search focus | Limited |
| Vacancy focus | Limited |
| Content approach | Company-focused rather than solution-focused |
| Performance score | ~40 |
| SEO operating model | Not yet structured around growth |

This gave us a clear order of operations. We did not start by simply publishing more content. We first needed to create the conditions in which organic growth could happen.

**Measurement → Technical foundation → Indexation → Search structure → Content → Growth**
